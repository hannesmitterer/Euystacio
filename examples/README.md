# Seedbringer Example Projects

This directory contains template projects demonstrating practical applications of the Seedbringer philosophy and technical stack.

## Available Examples

### 1. [Renewable Energy Tracker](./renewable-energy-tracker/)
Track and share community solar panel performance data on IPFS and blockchain.

**Use case**: Community solar cooperatives, environmental monitoring, transparency in renewable energy projects

**Technologies**: IPFS for data storage, blockchain for immutable timestamps, simple web interface

**Difficulty**: Beginner-Intermediate

---

### 2. [Community Knowledge Base](./community-knowledge-base/)
Collaborative wiki for preserving local knowledge, traditions, and skills.

**Use case**: Indigenous communities, local history preservation, skill sharing

**Technologies**: OrbitDB (distributed database), IPFS, peer-to-peer sync

**Difficulty**: Intermediate

---

### 3. [Ecological Monitoring System](./ecological-monitoring/)
Track biodiversity, water quality, soil health, and other environmental indicators.

**Use case**: Environmental NGOs, citizen science, agricultural communities

**Technologies**: IPFS, blockchain anchoring, data visualization, mobile-friendly

**Difficulty**: Intermediate-Advanced

---

### 4. [Open Educational Resources Platform](./open-education/)
Create, share, and remix educational materials with permanent, verifiable attribution.

**Use case**: Teachers, students, educational institutions, self-learners

**Technologies**: IPFS for content, blockchain for attribution, versioning system

**Difficulty**: Beginner-Intermediate

---

### 5. [Decentralized Document Vault](./document-vault/)
Preserve important documents with cryptographic proof of existence.

**Use case**: Legal documents, research papers, historical records, journalistic evidence

**Technologies**: IPFS, blockchain anchoring, encryption, simple CLI and web UI

**Difficulty**: Beginner

---

## Getting Started

Each example includes:
- **README.md**: Overview and setup instructions
- **Source code**: Complete, working implementation
- **Documentation**: How to deploy and customize
- **License**: Open-source (MIT or GPL)
- **Dependencies**: Minimal, well-documented

### Prerequisites

Most examples require:
- Node.js 18+ or Python 3.9+
- IPFS node (or access to IPFS gateway)
- (Optional) Blockchain wallet for anchoring
- Basic command-line skills

### Quick Start

```bash
# Clone the repository
git clone https://github.com/hannesmitterer/Euystacio.git
cd Euystacio/examples

# Choose an example
cd renewable-energy-tracker

# Install dependencies
npm install  # or: pip install -r requirements.txt

# Configure (edit .env file)
cp .env.example .env

# Run the example
npm start  # or: python app.py
```

## Contributing New Examples

We welcome new example projects! Ideal contributions:

- **Solve real problems**: Address actual community needs
- **Well-documented**: Clear instructions for setup and use
- **Accessible**: Usable by non-technical people where possible
- **Open-source**: MIT or GPL licensed
- **Sustainable**: Use decentralized, permanent infrastructure

### Contribution Process

1. **Discuss**: Open an issue proposing your example
2. **Build**: Create the project in a new subdirectory
3. **Document**: Write clear README and inline documentation
4. **Test**: Ensure it works for first-time users
5. **Submit**: Open a pull request with your example
