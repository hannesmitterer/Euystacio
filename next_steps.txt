## ⚠️ CRITICAL SECURITY NOTES

### DO NOT Commit Private Keys

**Private keys, service account JSONs, and other secrets must NEVER be committed to this repository.**

The following directories are gitignored and should remain empty in version control:
- `keys/`
- `keys-to-include/`

Any `.env` files with secrets should also never be committed.

### How to Set GitHub Secrets

Use the GitHub CLI to set required secrets:

```bash
# Required for contract deployment
gh secret set DEPLOYER_PRIVATE_KEY

# RPC URLs (use your own endpoints)
gh secret set SEPOLIA_RPC_URL
gh secret set MAINNET_RPC_URL
gh secret set POLYGON_RPC_URL

# For contract verification
gh secret set ETHERSCAN_API_KEY
gh secret set POLYGONSCAN_API_KEY
```

Or via the GitHub web interface:
1. Go to Repository Settings
2. Navigate to **Secrets and variables** → **Actions**
3. Click **New repository secret**
4. Add each secret with its name and value

## 🚀 How to Deploy

### Prerequisites
1. All secrets must be configured in GitHub Secrets
2. Have Node.js 18+ installed locally for testing
3. Have ETH in your deployer wallet for gas fees

### Deployment Options

#### Option 1: CI/CD Automatic Deployment
Push to a `deploy/*` branch to trigger testnet deployment:
```bash
git push origin deploy/euystacio-2025-11-29
```

#### Option 2: Manual GitHub Actions
1. Go to Actions tab
2. Select "Autideology CI" workflow
3. Click "Run workflow"
4. Select branch and run

#### Option 3: Local Deployment
```bash
# Set environment variables
export DEPLOYER_PRIVATE_KEY='your_key_here'
export SEPOLIA_RPC_URL='your_rpc_url'

# Run deployment
./scripts/run_deploy_locally.sh sepolia
```
